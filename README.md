# Project 3: Calendar Heatmap Dashboard

## Overview
This project analyzes app-category trends and growth patterns using a calendar heatmap, monthly growth calculations, and a three-month moving-average forecast.

## Tools Used
Python, Pandas, NumPy, Plotly, and Jupyter Notebook.
